Agent Deployment

Deploy the agent on remote servers to enable centralized scanning and monitoring.

Quick Install (one-liner)

curl -sL http://YOUR_SERVER:8443/api/agent/script | sudo bash -s run

Manual Install

wget http://YOUR_SERVER:8443/api/agent/script -O ioc_agent.sh chmod +x ioc_agent.sh sudo ./ioc_agent.sh register sudo ./ioc_agent.sh run &

Environment Variables

  • SERVER_URL - URL of this platform server
  • SCAN_DIR - Directory to scan (default: /)
